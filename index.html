申诉内容填写要求

申诉内容必须填写完善，请填写成本拆解，包括但不限于：商品成本、头程运费、仓储费、尾程运费、利润等

示例
商品款式：
商品成本：38元，采用的材料为牛奶丝；二次工艺：XX 辅料XX 等成本包含进去
头程：海运成本21元；清关：5元；尾程：USPS运输成本20；仓储：38元；售后：20元；利润：20元
  • 所有成本项应该单位一致且和核价单币种单位一致
  • 申报价请直接填数字，不要带其他格式
  • 竞品平台/竞品ID类型/竞品ID/相似款链接如有可填写，只填网址链接，没有空着，不要填"无"
  • 有重复值/不存在的SKC/申报价高于系统自己填的价格均会拦截申诉导致无法提交

市场推广提报

每周四一次提报推流品，满足以下要求有可能被市场选中推流
4 列字段
周四 提报周期

表格字段结构

列日期SPUID卖点（风格、元素、给款的原因）主销市场（美区/欧区）
说明提报日期商品SPU ID商品卖点描述美区 或 欧区
必填必填必填必填必填

提报要求

广告条件
广告可投 + 无广告/30天未投
商品评分
>= 4.5分 或 无评分
商品库存
>= 50

市场优先偏好

  • 优先精品高销品
  • 优先有站内视频的商品
  • 优先站内图/视频特别漂亮有吸引力的商品

提报流程

  • 第一步：在商品列表/上新生命周期筛选对应站点广告可投，且对应站点无广告/30天未投的商品
  • 第二步：确认商品评分 >= 4.5分 或 无评分
  • 第三步：确认商品库存 >= 50
  • 第四步：填写提报表格（日期、SPUID、卖点、主销市场）
  • 每周四提交，等待市场筛选选中推流
